# Geomagnetic-Field-Modeling-from-Swarm-Data
A MATLAB-based geophysical inversion tool that reconstructs the Earth's magnetic field using ESA Swarm satellite data. This project implements Spherical Harmonic Analysis (SHA) to estimate Gauss coefficients, evaluates model residuals against IGRF-12 standard reference fields, and generates global intensity, declination, and inclination maps.
